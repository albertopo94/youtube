# Canales en Estudio (Incubadora)

Esta carpeta aloja las investigaciones de viabilidad para nuevos canales antes de ser aprobados para producción.

## Cómo usar este espacio:
1. Crear una subcarpeta con el nombre del canal o nicho candidato:
   `canales-en-estudio/[nombre-candidato]/`
2. Copiar la plantilla `_framework/plantillas/estudio-canal-template.md` dentro de la carpeta como `estudio-mercado.md`.
3. Completar el análisis de competencia, outliers, propuesta de diferenciación y los primeros 5 videos con sus filtros de eliminación.
4. **Decisión:**
   - Si se aprueba: se traslada la carpeta a `mis-canales/[nombre-canal]/`.
   - Si se descarta: se elimina o se archiva.
