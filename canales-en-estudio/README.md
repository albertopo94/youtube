# Canales en Estudio (Incubadora)

Esta carpeta aloja las investigaciones de viabilidad para nuevos canales antes de ser aprobados para producción.

## Cómo usar este espacio:
1. Crear una subcarpeta con el nombre del canal o nicho candidato duplicando el contenido de `_plantilla-canal/`:
   `canales-en-estudio/[nombre-candidato]/`
   - `estudio-mercado.md`: Análisis DFS de competidores, outliers y demanda cualificada.
   - `propuesta-branding.md`: Concepto, tono, público y Unfair Edge Statement.
   - `backlog-ideas.md`: Ideas de video aprobadas en cola y temas descartados/vetados.
2. Completar el análisis de mercado y las primeras ideas.
3. **Decisión:**
   - Si se aprueba: se traslada íntegramente la carpeta a `mis-canales/[nombre-canal]/` (su backlog viaja con ella).
   - Si se descarta: se elimina o se archiva en ideas descartadas.
